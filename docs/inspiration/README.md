# Development Inspiration

This folder contains external references, articles, and design notes that may
inform future OpenShot development.

References recorded here are for research only. Application code must not rely
on an external webpage being available at runtime.

When adding a reference, include:

- Title and author
- Source URL
- Publication date, when available
- Date reviewed
- Relevant ideas and implementation notes
- Licensing or attribution requirements
- Known limitations or risks
